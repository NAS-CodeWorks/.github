# Contributing

Thank you for contributing to a NAS CodeWorks project.

Repository-specific instructions take precedence over this default guide.

## Before starting

1. Check existing issues and pull requests for related work.
2. Open an issue for a substantial change before implementation.
3. Keep the proposed scope focused and avoid unrelated refactors.

## Pull requests

- Use a clear title and explain the operational reason for the change.
- Include validation steps and test results.
- Document user-facing or configuration changes.
- Add screenshots for visible interface changes.
- Identify compatibility, security, performance, or migration risks.
- Do not include credentials, private data, generated binaries, or unrelated files.

All required repository checks must pass before merge.
