# Security Policy

## Reporting a vulnerability

Do not open a public issue for a suspected security vulnerability.

Use the repository's **Security** tab and submit a private vulnerability report when that option is available. If private reporting is unavailable, contact [hello@nascw.net](mailto:hello@nascw.net) with:

- The affected repository, version, or commit
- Reproduction steps or a proof of concept
- The potential impact
- Any suggested mitigation

Please avoid exposing sensitive data or exploiting the issue beyond what is necessary to demonstrate it.

## Scope and disclosure

Security support and release status are documented by each repository. Coordinate public disclosure with NAS CodeWorks after a fix or mitigation is available.
